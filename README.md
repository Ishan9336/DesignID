# Ishan Darbari — Portfolio Website

A fully self-contained, single-file professional portfolio website built with HTML, CSS & JavaScript.

---

## 📁 Folder Structure

```
ishan-darbari-portfolio/
├── index.html        ← Main website (open this in any browser)
├── README.md         ← This file
└── assets/           ← Place any custom images/icons here (optional)
```

---

## 🚀 How to Use

### Open Locally
Simply double-click `index.html` — it opens in any modern browser with zero setup.

---

## ✨ Features

- 🎨 **5 Color Themes** — Dark Amber, Midnight Blue, Emerald, Rose, Arctic Light
- 🖌️ **Full Customization Panel** — accent color picker, font switcher, background patterns, border radius, spacing
- 🤖 **AI Chat Agent** — pre-answered bot with Call & WhatsApp connect buttons
- 🌐 **Particle Canvas** — animated connected-node background in the hero
- ⌨️ **Typewriter Roles** — cycling animated job titles
- 📊 **Animated Stat Counters** — numbers count up on scroll
- 🔢 **Scroll Progress Bar** — thin accent bar at the very top
- 🖱️ **Custom Cursor** — accent-colored magnetic cursor
- 🌀 **Scroll Reveal Animations** — elements fade in as you scroll
- 📱 **Fully Responsive** — mobile hamburger nav, stacked layouts
- 🔝 **Back to Top** button
- 💾 **Preferences Saved** — theme & font persist via localStorage

## 🛠️ Customization Guide

### Change Your Name / Bio
Open `index.html` in any text editor (VS Code recommended) and search for:
- `"Ishan Darbari"` — your name
- `.hbio` section — your hero bio text
- `#ccore` / `#ctech` arrays — your skills

### Change Contact Details
Search for `8318375506` to update phone/WhatsApp number.
Search for `ishandarbari012@gmail.com` to update email.

### Change Accent Color on Load
In the `:root` CSS block, edit `--accent` and `--accent-rgb`.

### Add a Profile Photo
Replace the SVG orbit decoration in the hero section with an `<img>` tag pointing to your photo inside the `assets/` folder.
